# ✈️ 6FAEX Program — Integrated Carrier Air Combat Ecosystem

## 🧭 Overview

The 6FAEX program (6th gen Fighter Attack Electronic eXperimental) is the Oceanic Federation Navy’s unified next-generation carrier aviation system.

It produces three tightly integrated airframe roles that function as a single combat network rather than independent aircraft types:

- FA-55 Banshee — kinetic strike platform  
- EA-55 Siren — electronic warfare / command control platform  
- UA-55 Will’O’Wisp — autonomous loyal wingman system  

All three share:
- FA-55-derived stealth airframe architecture  
- Holton Bronco propulsion system  
- carrier integration systems and maintenance pipelines  

---

## 🎯 SYSTEM ROLE DIVISION

### 🛩️ FA-55 Banshee — “The Brawler”
Primary kinetic combat asset of the system.

- air superiority engagements  
- precision strike operations  
- anti-ship warfare  
- CAS support in contested environments  

> Executes physical damage in the battlespace

---

### 📡 EA-55 Siren — “The Controller”
Electronic warfare and battlefield coordination node.

- electromagnetic spectrum control  
- sensor jamming and deception  
- battlefield network disruption  
- coordination of FA-55 and UA-55 assets  

> Shapes the battlespace before and during engagement

---

### 🤖 UA-55 Will’O’Wisp — “The Minions”
Autonomous / semi-autonomous loyal wingman systems.

- reconnaissance and scouting  
- missile sponge / decoy functions  
- sensor extension nodes  
- strike augmentation support  

> Extends reach, density, and survivability of the air wing

---

## ⚓ DOCTRINAL STRUCTURE

The 6FAEX system is not composed of separate aircraft classes.

It is a **single distributed combat organism**:

- EA-55 = cognitive layer (control / perception / disruption)
- FA-55 = physical execution layer (kinetic force)
- UA-55 = distributed extension layer (presence / saturation / support)

---

## 🧠 SYSTEM BEHAVIOUR MODEL

In combat operations:

- EA-55 defines engagement space and conditions  
- FA-55 executes targeted strikes within controlled environment  
- UA-55 expands sensor coverage and overwhelms enemy response cycles  

This creates a layered warfare model where:

> control of information precedes control of force, and force is multiplied through autonomous extension

---

## 📌 SUMMARY

The 6FAEX program represents a unified carrier strike doctrine in which FA-55, EA-55, and UA-55 are functionally interdependent components of a single distributed aerial combat system rather than discrete aircraft types.
